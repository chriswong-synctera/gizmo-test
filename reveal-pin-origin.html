Reveal PIN Widget

The reveal-pin widget securely reveals a card PIN using a widget token. The PIN is fetched, rendered, and auto-hidden entirely within a Synctera-origin iframe and never reaches the parent page.

Widget Demo (Self-Contained with Show PIN button)

This widget includes a built-in "Show PIN" button. The PIN auto-hides after the configured number of seconds (default 5s).

This widget hides the built-in button. Trigger the reveal with requestPin() via the buttons below.

How to Get a Widget Token

To reveal a PIN, you need a widget token from the Synctera API: 

GET /v2/cards/{card_id}/widget_token?widget_type=GET_PIN

Response:
{
  "tenant": "abcdef_ghijkl",
  "widget_token": "0b0319e2-d5f4-49cb-b426-9ff9b2e96969"
}
